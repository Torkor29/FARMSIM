# 51 — L’ETA n’est pas une spécialisation

**Statut :** A–D en code (cette branche). F–G (vraies parcelles PNJ, P2P) plus tard.  
**Date :** 2026-08-13

On n’est pas « ETA ». On est **céréalier** ou **éleveur**. Les travaux à façon sont un appoint : du fer idle va chez le voisin le temps que ça pousse.

## En jeu maintenant

- Onboarding : **2 métiers**. Comptes déjà ETA → céréaliers, machines gardées.
- Tableau Bureau : **3 chantiers** max, **8–24 cases**, une mission à la fois.
- Prendre un chantier ouvre un **mini-jeu** : glisser sur les cases, puis encaisser.
- Salaire PNJ = **55 %** du devis client. Urgent « Entreprise » = barème **+15 %** (l’argent sort).
- Graisse / nettoyage / atelier : **pour tout le monde**. Plus de +5 %, plus de moissonneuse offerte, plus de remise de caste.
- Critère : 3 moissons de tableau < semer et vendre 24 cases de blé.

Le plan détaillé (tables, boucle solo, P2P) reste la référence de conception d’origine.
