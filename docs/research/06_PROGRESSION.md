# 06 — Progression (niveaux, spécialisations, machines, R&D)

---

## 1. Philosophie

> Le matériel, les décisions et l’organisation battent le niveau.  
> Les niveaux restent **faibles**. Les spécialisations restent **faibles**.

Plafonds globaux `[GD]` :
- bonus niveau total ≤ **+10 %**
- bonus spécialisation total ≤ **+10 %**
- cumul soft-capé (pas 1.10 × 1.10 libre sur tout) — appliquer des domaines disjoints autant que possible.

---

## 2. Niveau joueur

XP via : travaux réussis, récoltes, contrats, prestations, achievements.

| Niveau | Exemple bonus `[GD]` | Domaine |
|--------|----------------------|---------|
| 10 | +2 % vitesse travail | Opérations |
| 20 | +5 % | Opérations |
| 50 | +7 % | Opérations |
| 100 | +10 % (cap) | Opérations |

**Ne donne pas :** supermultiplicateur prix, immunité météo, unlock payant exclusif critique.

Unlocks non-stat : recettes UI, 2e emplacement bâtiment, accès R&D tier, etc. (préférable aux +%).

---

## 3. Spécialisations

Choix initial (modifiable rare / coûteux `[PROPOSITION]`).

### Céréalier
- +rendement céréales
- −coût stockage céréales
- +efficacité outils sol/récolte

### Éleveur
- +conversion feed
- +santé
- +qualité animalière

### Futur : Entrepreneur
- +réputation contrats
- −usure en prestation
- +vitesse matching

Magnitude : +2 % → +5 % → +10 % selon palier de maîtrise **dans la spé**, pas cadeau jour 1.

---

## 4. Machines = vraie progression

Attributs :
- coût, puissance, largeur, vitesse, capacité, conso, entretien, usure, fiabilité.

Tiers : T1 starter → T2 mid → T3 heavy.  
Location early game.  
Occasion / usagé `[V1]` : moins cher, usure haute.

**Usure `[PROPOSITION]` :** sink monétaire + raison d’acheter T3 / entretenir.

Largeur × vitesse = throughput cases/heure → lien direct avec grille parcellaire.

---

## 5. R&D semences

Laboratoire ferme (bâtiment) :
- points recherche via essais au champ (coût + risque) ;
- unlock variants avec **compromis visibles**.

Exemples de branches :
- Yield branch
- Drought branch
- Quality branch
- Early maturity branch

Impossible d’empiler tous les max.  
OGM = branche réglementée régionalement (post-MVP).

---

## 6. Terrains

Expansion limitée par :
- capital ;
- slots d’exploitation ;
- distance / gestion (malus multi-parcelles lointaines) ;
- réglementation locale future.

Évite snowball purement spatial.

---

## 7. Ce qu’on refuse

- Battle-pass qui vend +50 % yield
- Prestige resets qui cassent l’économie sans sinks
- Paywall machines T3 exclusives cash only

---

## 8. Feeling de progression (UX)

Le joueur doit *voir* :
- champ plus propre / plus vert ;
- machine plus large ;
- silo plus grand ;
- graphique marge ;
- badge spé discret.

Pas seulement un chiffre « Level 47 ».
